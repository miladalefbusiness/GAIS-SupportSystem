# سامانه پشتیبانی هوشمند سازمانی و مخزن فایل اشتراکی

پلتفرم مستقل، امن و خودمیزبان شامل چهار فضای کاری یکپارچه:
1. **پورتال عمومی پشتیبانی مشتریان** (`/`)
2. **میز کار اپراتورها** (`/workspace` - فاز ۲ و ۴)
3. **مخزن فایل اشتراکی سازمانی** (`/workspace` - فاز ۵)
4. **پنل مدیریت ارشد (Super Admin)** (`/workspace` - فاز ۱ تا ۶)

---

## وضعیت پیشرفت فازها

| فاز | عنوان | وضعیت |
| :--- | :--- | :--- |
| **فاز ۱** | هسته معماری، پایگاه داده، احراز هویت، RBAC، ذخیره‌سازی، Docker و CLI | **تکمیل‌شده (جاری)** |
| فاز ۲ | مدیریت دپارتمان‌ها، لیست عمومی پویا، اپراتورها و عضویت دپارتمانی | در انتظار |
| فاز ۳ | مدیریت مخزن دانش (اسناد + Q&A)، بازیابی RAG و اتصال ارائه‌دهنده AI | در انتظار |
| فاز ۴ | احراز هویت مشتری (کد ملی رمزنگاری‌شده + OTP)، تیکتینگ و توزیع عادلانه | در انتظار |
| فاز ۵ | مخزن فایل اشتراکی، پوشه‌بندی و سهمیه حجمی دپارتمانی | در انتظار |
| فاز ۶ | گزارش‌های جامع، تنظیمات سیستم و گزارش ممیزی پیشرفته | در انتظار |
| فاز ۷ | مقاوم‌سازی امنیتی نهایی، آزمون نفوذ، تست بازیابی و مستندسازی نهایی | در انتظار |

---

## راه‌اندازی سریع محلی (توسعه)

```bash
npm install
cp .env.example .env
# مقداردهی متغیرهای SQL_* و BETTER_AUTH_SECRET و SUPERADMIN_* در .env
npm run db:generate
npm run db:migrate
npm run db:bootstrap
npm run dev
```

## استقرار خودمیزبان با Docker

```bash
chmod +x bin/supportdesk
./bin/supportdesk install
```
برای جزئیات کامل استقرار، پشتیبان‌گیری و بروزرسانی به `DEPLOYMENT.md` و `BACKUP-RESTORE.md` مراجعه کنید.
